What changes with Copilot

Copilot uses the access
you already gave people

Most AI tools only know what you paste into them. Microsoft 365 Copilot is different. It works inside your email, Teams chats, meetings, OneDrive and SharePoint, and it can draw on anything the person using it is allowed to open.

The one sentence to remember

Copilot doesn't create new access. It finds and uses the access people already have, including access nobody meant to give them. Microsoft's own SharePoint guidance says Copilot can surface broadly shared files a user didn't know they could see.

Question 1 of 6

Owner: who owns
the outcome?

Every Copilot use case and every agent in production has a named business owner. One person, with a title, whose name is on the result.

NOT THIS

"IT turned on Copilot, so IT owns it."

THIS

"The VP of Human Resources owns the 360 summary agent and decides who can use it."

Why this matters more with Copilot

In Microsoft 365, anyone with a Copilot license can build an agent with Agent Builder and share it with colleagues. That's useful, and it means agents can multiply quietly. Each one needs an owner who answers for what it does.

Three things give ownership teeth, the Microsoft way

What it needsWhere it lives in Microsoft 365
A logCopilot activity is recorded in the Microsoft Purview audit log. How long it's kept depends on your license, so check before you rely on it.
An off switchAdmins can block or unblock an agent for the whole organization from the Agents page in the Microsoft 365 admin center. A person's access can also be removed by unassigning their Copilot license.
A review dateNo setting does this for you. Put it on the owner's calendar, and review the agent inventory at the same time.
Worth asking IT

Who holds the AI Administrator role in your tenant? Several of the settings in this guide need that role, and that person should know who the business owners are.

Question 2 of 6

Data: what does Copilot
need to know?

Copilot can draw on email, chats, meetings and files. For any one task it needs far less. Give each use case the minimum, and label the rest so Copilot treats it with care.

Four classes, mapped to sensitivity labels

Public

Website copy, press releases. Label: Public.

Internal

Process docs, meeting notes, FAQs. Label: General.

Confidential

Contracts, financials, employee records. Label: Confidential.

Restricted

SSNs, bank details, health information, privileged legal. Label: Highly Confidential, with encryption.

Label names vary by organization. Match these four classes to the labels your tenant already uses.

What labels do for Copilot

  • Copilot respects encryption. If a label encrypts a file and the person doesn't have the right to copy content from it (Microsoft calls this the EXTRACT right), Copilot can't show them its text. It can only point to the file.
  • Labels travel with answers. Copilot shows the labels of the files it used, and new content created from a labeled file can pick up that label.
  • Labels need a person to set them up. Publishing labels and deciding which are encrypted is a Purview task. If nobody has done it, Copilot has nothing to respect.

Four ways to handle the data, safest first

1

No sensitive data required

2

Redacted or anonymized data

3

Synthetic or example data, like a made-up 360 for a demo

4

Real confidential data, labeled, in a site with the right permissions
Example: summarizing 360 feedback

Copilot needs one person's ratings and comments from the Forms export. It doesn't need other employees' reviews, pay data, medical leave records or the rest of the HR site.

Question 3 of 6

Environment: where is it
processed, and who else
touches it?

"We use Copilot" doesn't tell you enough. These are different environments, with different controls:

Consumer Copilot

Signed in with a personal Microsoft account. Not for work data.

Copilot Chat

Work account, no Copilot license. Uses the web and files you upload.

Microsoft 365 Copilot

Licensed. Also draws on your email, chats and files.

Agents

Built in Agent Builder or Copilot Studio, with their own knowledge and tools.

Five checks, answered for Copilot

CheckWhat to confirm in Microsoft 365
1 AccountPeople sign in with their work account. That's what turns on enterprise data protection, which covers both Copilot Chat and Microsoft 365 Copilot.
2 TrainingUnder enterprise data protection, Microsoft says prompts, responses and the data Copilot reads aren't used to train its foundation models.
3 RetentionPurview retention policies can cover Copilot prompts and responses, but they aren't retroactive, so set them before rollout. Files uploaded to Copilot Chat are saved in the person's OneDrive. Copilot's memory feature isn't covered by standard holds.
4 ContractCopilot runs under Microsoft's Product Terms and Data Protection Addendum. I flag questions about them and route them to legal; I don't interpret contracts.
5 Vendor chainWeb search: Copilot can send search queries to Bing. Admins can turn this off with a policy.
Model choice: when an admin allows it, people can choose Claude, Anthropic's model, for an answer in Microsoft 365 Copilot. Anthropic then processes that request as a Microsoft subprocessor. The admin setting decides whether the choice exists; each person decides when to use it. As of November 2026, Claude in Copilot runs outside Microsoft's EU Data Boundary, which matters for UK and EU clients.
Agents and connectors: each one is another path for data.
Worth saying out loud

Never assume "enterprise Copilot" means every control you want is switched on. Web search and model choice are tenant settings, and someone has to decide how to set them.

Question 4 of 6

Access: what can
Copilot reach?

Least privilege still applies: Copilot should only reach what the job needs. In Microsoft 365, that comes down to permissions, because Copilot works as the person using it and sees what they can see.

The real risk is oversharing

Old SharePoint sites, "anyone in the organization" links and large Teams memberships give people access they never use. Before Copilot, nobody stumbled on those files. With Copilot, a plain question can bring them up.

Microsoft's tools for finding and fixing it

ToolWhat it does
Data access governance reportsShow sites that are shared broadly or have sharing links, so you know where to look first.
Restricted Content DiscoveryKeeps a site out of Copilot and organization-wide search results without changing anyone's permissions. A good stopgap while you clean up.
Restricted access controlLimits a site to the members of a named group.
Sensitivity labels on sitesSet privacy and sharing rules for a whole site or team.

These SharePoint Advanced Management features become available once at least one Microsoft 365 Copilot license is assigned. A few features still need a separate add-on.

Same tool, two risk profiles

Agent A: answers from one folder

An Agent Builder agent that answers HR policy questions from one approved SharePoint folder. If it's wrong, a person reads a bad answer.

Agent B: reaches and acts everywhere

An agent that can read all mailboxes and sites, send email and update calendars. If it's wrong, it can send, forward or book the mistake.
Access is what it can reach. Action is what it can change.

Set access before files move into SharePoint, not after Copilot finds them.

Question 5 of 6

Action: what can
Copilot change?

The big line is between Copilot that recommends and Copilot that acts. In Microsoft 365, which Copilot you use largely decides which side of that line you're on.

RecommendsActs
"Draft a reply to this candidate" in OutlookAn agent that replies to candidates on its own
"Summarize this 360 file" in Copilot ChatAn agent that emails summaries to managers automatically
"Which times work for all four interviewers?"An agent that books, moves and cancels interviews

The autonomy ladder, with Microsoft examples

LevelWhat it meansWhere you'll see it in Microsoft 365
0 AnswersResponds to questionsCopilot Chat. An Agent Builder agent answering from approved files.
1 RecommendsA person decides and actsCopilot suggesting meeting times, flagging themes in comments
2 DraftsA person reviews, then sends or files itCopilot in Word, Outlook and Excel. You press Send.
3 Acts after approvalA person approves every actionCopilot Studio agents with actions set to ask before they run
4 Acts within limitsActs alone inside written limits, and logs everythingCopilot Studio agents with triggers and connectors
5 Plans its own stepsDecides its next steps across systemsCopilot Cowork, which breaks a goal into tasks across Outlook, Teams and Office, and can be allowed to use a browser

Good starting point

Copilot Chat and Agent Builder keep you at levels 0 to 2. They're included with Microsoft 365 Copilot and don't need an IT project.

Needs IT and governance first

Copilot Studio actions and Cowork reach levels 3 to 5. Cowork must be turned on by an admin, uses usage-based billing, and keeps browser use off unless an admin allows it.
Organizations earn their way up the ladder

Move up one level only after a trial period, tracked errors and the owner's sign-off. Nobody should start at the top.

Question 6 of 6

Oversight: where must
a human decide?

Tie human approval to consequence and how hard the action is to reverse. Then make sure there's a record.

GREEN Copilot can do it

Formatting a document. Summarizing a public article. Turning meeting notes into a task list.

YELLOW Copilot drafts, a person approves

Job descriptions. Candidate emails. 360 summaries before they reach a manager.

RED A person owns the decision

Hiring, pay, promotion, discipline and termination. Legal conclusions. Anything a regulator could ask about.

The Microsoft paper trail

WhatWhy it matters
Purview audit logRecords that Copilot interactions happened, with the user, time and app. How long logs are kept depends on your license.
Retention policiesKeep Copilot prompts and responses for as long as your records rules require. Set them before rollout, because they don't reach back.
eDiscoveryLets legal and compliance find and export Copilot prompts and responses for an investigation.

For regulated firms, ask compliance which of these your recordkeeping rules require before anyone uses Copilot with client or employee information.

The output check

Controls on what goes in don't cover what comes out. Before anything Copilot produced is used:

Is it true?

Numbers, names and facts checked against the source file. Excel does the math, not the chat.

What's in it?

No sensitive detail carried in by accident. Check the label Copilot shows.

Where does it go?

Who will see it, and is the sharing link set to the right people?

A quick test for any use case

The red-flag test,
in Microsoft 365

Simon Willison calls it the lethal trifecta: an AI that has all three of these at once. Here's what each one looks like in Copilot.

The flagIn Microsoft 365, it looks like
1 Access to private dataLicensed Copilot reading mailboxes, chats, OneDrive and SharePoint
2 Exposure to untrusted contentEmails from outside, résumés, vendor PDFs, web search results, documents shared in from other companies
3 A way to send information outSending email, posting in Teams, creating sharing links, Copilot Studio connectors, Cowork with browser use on
The rule

If a use case has all three, it's red by default until a control removes one. Keeping Copilot at Draft, where a person presses Send, takes away the third.

When the model gets fooled

Emails, résumés and PDFs can carry hidden instructions that Copilot reads as commands. Microsoft builds in its own defenses, and the framework doesn't rely on them alone. Each layer limits the damage on its own:

LayerThe Microsoft 365 control
OwnerSees it in the audit log and blocks the agent from the admin center
DataEncrypted labels keep restricted text out of answers
EnvironmentWork accounts, web search policy, AI provider settings
AccessTight permissions and Restricted Content Discovery
ActionDrafting tools first, approvals on any action that sends or changes something
OversightA person approves the consequential step, and Purview keeps the record

Worked example

"We want Copilot to
summarize our 360 feedback"

The answer doesn't start with prompts. It starts with the six questions.

QuestionThe answer
OwnerThe VP of Human Resources, with a review date after the first cycle
DataOne person's ratings and comments from the Forms export. Confidential. Summaries get the Confidential label.
EnvironmentLicensed Microsoft 365 Copilot with a work account. Web search off for this task. Compliance has decided whether people may choose Claude for it.
AccessExports and summaries live in a private HR site, set up before any files move. Managers see only their own people's summaries.
ActionLevel 2. Copilot drafts the summary and Excel does the math. A person reviews it, saves it and shares it. Later, an Agent Builder agent can run the same steps, still at level 2.
OversightHR reads every summary before a manager sees it. Ratings, pay and promotion decisions stay with people. Groups smaller than three are left out to protect anonymity.

Red-flag test

Yes private data
Partly untrusted content (free-text comments)
No way to send at level 2

YELLOW Grid result

Confidential at Draft. A person reviews before anything leaves HR. Moving to automatic emails to managers would add the third flag, so every send would need approval.
Only after those decisions

do we write the prompts and build the agent.

Before you roll out

Ten Copilot settings
to look at first

Take this list to whoever runs your Microsoft 365 tenant. Most are a short conversation, not a project.

Setting or decisionQuestion to ask
1Who has the admin rolesWho is our AI Administrator and Global Administrator?
2Copilot licensesWho has a Microsoft 365 Copilot license, and who only has Copilot Chat?
3Web searchIs web search on in Copilot, and for whom?
4AI providers operating as Microsoft subprocessorsCan our people choose Claude in Copilot? Has compliance said which data they can use it with?
5Cowork and usage-based billingIs Cowork on? If so, for whom, with what spending limits, and is browser use off?
6AgentsWho can build and share agents? Who reviews the agent inventory?
7Oversharing reportsHave we run the data access governance reports in SharePoint?
8Restricted Content DiscoveryWhich sensitive sites should be kept out of Copilot until permissions are cleaned up?

Microsoft renames and moves Copilot settings often. Confirm current names and paths on Microsoft Learn or in your admin center before you rely on this list.
